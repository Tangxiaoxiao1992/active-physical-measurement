# Active Physical Measurement

**Research project in development — 研究立项草案**

面向视频定量物理问答，研究视觉语言模型如何提取可核查的测量条件，并在有限预算内选择有效的补测动作。

当前状态：已有人工初始化的台球跟踪与局部轨迹拟合原型，以及木块测量证据标注示例。自动条件提取、错误诊断和补测策略尚未完成。本文件是研究计划，不代表已验证的新方法、论文录用或优先权声明。项目与 QuantiPhy 主办方无隶属关系。

## Research question

在相同计算预算下，根据测量异常及其对最终答案的影响选择补测动作，是否比固定采样、随机补测和通用自我检查更准确？

我们的候选方法包括：

1. 由视觉语言模型解析问题，确定目标、参考物、测量维度和时间。
2. 通过视觉工具提取坐标、轮廓、轨迹和尺度；记录真实工具输入输出。
3. 将观测、假设、几何关系和计算结果分别存储，并关联到原始帧。
4. 检查测量异常，估计不同补测动作的潜在收益与成本。
5. 选择重新定位、重测尺度或调整时间窗口，并由程序计算答案。

异常不等于错误：轨迹突变可能来自真实碰撞，跨帧差异可能来自透视变化。系统应检查原因，不能强制平滑或强制物理一致。

## Evaluation protocol

- 按视频划分开发集与留出集；同一视频的不同问题不得跨越两者。
- 人工正确端点、参考物和几何关系仅用于诊断对照，不能算自动方法表现。
- 在相同工具、输入分辨率和预算条件下比较策略，并保存模型版本、提示词、采样参数和重复结果。
- 报告数值误差、阈值通过率、失败率、工具调用次数、帧数、tokens 和成本；按视频汇总，避免将重复请求当作独立样本。
- 标准答案只用于开发阶段的评分与动作收益分析，不参与测试时选帧、选动作或选择最终答案。
- 同时记录补测改善率与恶化率。若可用动作即使事后选择也无法改善，应先修复测量工具。
- 保存原始帧标识、尺寸、时间戳、坐标系、工具输出、单位、尺度来源、几何假设与可回画标注。模型自称使用工具不视为执行证据。
- 终止策略需检查过早停止及稳定偏差，不能仅凭模型自报置信度。

## Related work and positioning

本项目复用成熟方法，不把工具调用、结构化输出、画点或局部多项式拟合本身作为创新。

- [ViperGPT](https://github.com/cvlab-columbia/viper)：图像和视频上的程序化视觉推理。
- [OpenThinkIMG](https://github.com/OpenThinkIMG/OpenThinkIMG)：视觉工具调用、交互推理和训练框架。
- [LeafMachine2](https://github.com/Gene-Weaver/LeafMachine2)：标本图像中的尺子尺度换算、测量和检查图。
- [VideoAgent](https://arxiv.org/abs/2403.10517)：迭代收集视频证据。
- [Think, Then Verify](https://arxiv.org/abs/2603.04977)：视频假设与证据核验。
- [VeriPhy](https://arxiv.org/abs/2609.03153)：可追溯的物理检查计划、测量与证据记录。
- [QuantiPhy](https://quantiphy.stanford.edu/)：定量物理视频问答评测任务。

候选贡献是面向最终数值误差的补测动作选择。其新颖性和有效性仍需进一步文献核对及对照实验，不声称首次提出主动测量或物理核验。
